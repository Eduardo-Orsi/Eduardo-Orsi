## Selected work

### [Dr. Creators](https://drcreators.com/)

Creator-data SaaS built end to end with **Next.js Server Components, Auth.js, PostgreSQL, Redis, Docker, and Coolify**. The platform supports more than **400,000 creator profiles** and includes a Chrome extension for on-demand data enrichment.

### E-commerce data platform

Designed and built a platform with **Python, FastAPI, Redis, PostgreSQL, webhooks, and scheduled API polling**, integrating e-commerce, advertising, ERP, and logistics providers. It processed more than **3 million events in six months**, enabled UTM-based sales analysis, and helped identify at least **BRL 25,000 in shipping losses in a single month**.

### [Real-time order tracking](https://rastreio.querolove.com/)

Stateless tracking application built on **Cloudflare Workers**, retrieving shipping information through real-time APIs without a database. It integrates **Shopify, Yampi, Loggi, J&T, and Correios**.

### Shopify and e-commerce engineering

Customized Shopify storefronts with **Liquid**, integrated the **Shopify GraphQL API**, and built **Videofy**, a video-shopping application that completed Shopify App Store review and approval.
